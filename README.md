# Cutwave

- Fast cut without re-encoding, or frame-accurate precise cut
- Compress to a target size (WhatsApp, Discord, email, Telegram)
- Extract audio to MP3
- Volume control from 0% to 300% with live preview
- Hardware acceleration with WebCodecs
- Opens large files of several GB
- Files never leave your device
- Drag and drop
- Works on mobile and desktop
- Installable app that works offline
- Share the result directly from your phone
- Dark and light theme
